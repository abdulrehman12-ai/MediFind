# Customer access uses Sanctum personal access tokens

Customers authenticate with bearer tokens issued by Laravel Sanctum. Tokens last 30 days, allow only `customer:access`, and are stored as hashes. Logout and logout-all delete token rows. Account suspension, soft deletion, and a role change away from `customer` delete tokens. Suspension is enforced in application code and again in a PostgreSQL trigger. The trigger also covers soft deletion and leaving the customer role. Restoring the customer role does not recreate deleted tokens. SPA cookie authentication is not enabled. Sanctum stateful domains are an empty list, and `EnsureFrontendRequestsAreStateful` is not registered.
